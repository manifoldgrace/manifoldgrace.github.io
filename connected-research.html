How records are connected

Zenodo and DOI links identify archived, publicly released research outputs. ORCID identifies the researcher and links to public works. GitHub hosts version-controlled supporting materials. Google Docs remains the private, editable authoring source unless a specific document and version are approved for public publication.

Public Google Docs export: not enabled. The approval register is empty by default. Website visitors cannot edit source documents, and a read-only website page does not change Google Drive permissions.
