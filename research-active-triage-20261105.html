A coherent first research-delivery bundle

Rather than expanding every domain simultaneously, combine the first, second, third and tenth streams into one bounded, inspectable demonstration. The proposed bundle has four reusable parts:

  1. Synthetic evidence pack: 15 fictional, non-sensitive claim/source pairs, with several conflicting dates, changes of definition and missing references. Make clear they are illustrative rather than real institutional findings.
  2. Machine-readable claim ledger: statement, source, source version, timestamp, explicit versus inferred relationship, supported/disputed/unknown label, review status and correction history.
  3. Reference rubric: evidence coverage, contradiction correctness, temporal reasoning, abstention when uncertain, authorisation, latency and computation estimates when measured.
  4. Transparent test demonstration: compare a basic summariser with a deterministic evidence-aware checker; only later test actual model agents with comparable resources and independent adjudication.

These are specifications for a first bundle, not claims that the datasets, code, experiments or expert reviews have already been produced. The existing evaluation protocol supplies the methodological constraints and the research lab provides an appropriate educational context.

First reusable artefact: synthetic claim test pack

Version 0.1 contains 15 fictional claim pairs with reference relation labels, rationales and explicit synthetic provenance. The examples cover contradiction, temporal compatibility, changed rules, scope and metric mismatch, missing evidence, formal-proof overclaims, uncertainty, attribution and dependency review. These are illustrative reference annotations, not an empirically validated benchmark. Open the machine-readable JSON test pack.

Starter scoring: evaluate relation classification accuracy per category, false contradiction rate, abstention on ambiguous cases and explanation faithfulness; record human disagreements, model and prompt versions, tool permissions, latency and measured resource use. Do not attach measured accuracy or a confidence interval until actual repeated trials have been performed.

Claim verification and terminology safeguards

Supported: GPT-6 Astra exists; ARC Prize publishes ARC-AGI-3 results and distinguishes Standard from Provider Adapter harnesses; DeepMind published the From AGI to ASI report and AlphaEvolve. Qualified: “System 2” is an analogy for deliberate computation, not evidence that every model implements human dual-process cognition. Reinforcement learning, search, evaluation and externally structured agent loops are distinct mechanisms. Unresolved or over-broad: AGI as an agreed imminent milestone, an asserted universal ASI threshold of “ten thousand experts for ten years”, blanket 95% medical diagnostic accuracy, and claims that static evaluation has become obsolete. Static fixtures remain useful alongside dynamic environments, adversarial tests and longitudinal assessments.

Specific benchmark caution: ARC Prize's GPT-6 Astra comparison reports 62.7% under a Standard harness at maximum reasoning versus 99.9% with a Provider Adapter at high reasoning. The configuration changes the interpretation. Comparison should retain the task partition, memory policy, compute budget, source timestamp and external-tool permissions.
