# AI System Evaluation — Project Template
**Status:** Reusable technical evaluation template; not an implemented benchmark.

## Purpose
Test an AI model or system on a discipline-specific task against defined baselines and independent evidence.

## Protocol
- Research question and task boundaries
- Test dataset provenance, consent, licensing and exclusion criteria
- Baseline system and model/version specifications
- Methods and preregistered metrics (accuracy, coverage, reliability, fairness, uncertainty, latency, cost where relevant)
- Human/expert review and inter-rater agreement
- Error taxonomy, contradiction checks and adverse or out-of-distribution cases
- Repeated trials, scripts, environment details and audit logs
- Reporting of negative results, limitations, correction history and potential harms

## Deliverables
Dataset manifest, evaluation rubric, executable tests (if built) and evidence-based findings.

_No dataset or working system is supplied as part of this reusable template._
