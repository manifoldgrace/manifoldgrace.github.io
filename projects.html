Learning and preparation

The 2024/25 programme specification lists nine outcomes. The numbers above refer to AI foundations (1), ethical evaluation (2), case studies (3), applied ethical reasoning (4), policy and regulation (5), critical discussion (6), communication (7), independent research (8), and interdisciplinary collaboration (9). Outcome 9 needs actual participation and documented feedback.

For each build, record the upstream source and version, licence and notices, installation steps, synthetic fixtures, a working baseline commit, and an experiment branch. Add a data-flow diagram, an acceptance test, a note on what broke, and a record of what you changed. Capture the test result before linking a working demo.

Use WebLLM for browser inference and GitHub Pages for static demos. Run Node-RED, Frappe CRM, ERPNext and Django locally for experiments that need a backend. Verify the specific release and licence before distributing a modified baseline.

Test expected challenges early: replacing a model or provider, recovering from failed workflows, retaining evidence versions, enforcing access rules, exporting data, and keeping the interface accessible.
