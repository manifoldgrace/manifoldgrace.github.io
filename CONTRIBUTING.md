# Contributing to Manifold Grace

Manifold Grace is independently founded. Contributions do not confer founding status, board membership, employment, ownership or authority to represent the initiative.

Welcome areas include evidence provenance, data quality, AI evaluation, accessibility, information governance, software engineering, archival research and review of documented source claims.

## Proposal and review
1. Open an issue describing a **non-confidential** improvement, source or reproducible technical test.
2. Identify the exact claim or file, proposed change and supporting primary documentation.
3. Submit a focused pull request without replacing unrelated website content or altering the established visual design.
4. Report contradictions and limitations; distinguish original declarations from independently validated outcomes.
5. Preserve old findings through version control and explain corrections in the PR description.

**Do not post** personal data, private communications, credentials, whistleblower disclosures, employment or medical records in public issues or pull requests. No secure reporting or upload portal is operational.

Before reuse of contributed code, documentation or data, confirm appropriate licensing and authority; an accepted contribution is not an automatic IP assignment.

See [Evidence Integrity documentation](docs/evidence/README.md).
