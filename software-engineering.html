TECHNICAL PORTFOLIO

Builds with explanations

Projects can be presented as compact engineering narratives: problem, architecture, implementation, security considerations, testing, failure modes and next iteration. Code blocks are useful where they illuminate a decision, but the page should remain intelligible to someone who is not reading an entire repository.

This format also supports ethical analysis. An algorithm or infrastructure choice can be examined technically and then connected to questions of observability, data use, access, reliability, power or governance.
