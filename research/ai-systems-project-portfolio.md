# Manifold Grace AI Systems — Project Portfolio Register

Date: 9 November 2026
Status: Public research and prototype catalogue; no private service deployed.

Each project will have: purpose, intended user, demo link, architecture, data boundaries, model baseline, test cases, benchmark, security assessment, reproducibility notes, version, cost estimate, service/monetisation hypothesis and evidence of actual deployment.

## Research infrastructure contribution — implemented 10 November 2026

[Evidence and Contradiction Evaluation Harness](evidence-contradiction-benchmark/README.md): executable Python evaluator, twelve author-labelled synthetic practice fixtures, a lexical baseline and challenge-disaggregated scores. This is an openly inspectable engineering artefact, not a validated model benchmark. It extends the existing research assistant track without duplicating its browser demonstration.
